# 记

记行程、记三餐、记每一笔。一个手机优先的单页应用：出行清单、事件报备、预约提醒、出行记录、常用项、票据、食谱与记账。

没有后端、没有账号，**所有数据只保存在你自己设备的浏览器里**，不会上传到任何地方。

## 部署到 GitHub Pages（约 3 分钟）

1. 在 GitHub 新建一个仓库（免费账号需选 **Public**），名字随意，例如 `ji`。
2. 点 **Add file → Upload files**，把本文件夹里的**所有内容**拖进去（包括 `icons` 文件夹和 `.nojekyll`），点 **Commit changes**。
3. 进入仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main`、目录选 `/ (root)`，保存。
4. 等一两分钟，页面顶部会出现网址：`https://你的用户名.github.io/仓库名/`。

> 如果拖拽后看不到 `.nojekyll`（以点开头的文件有时会被系统隐藏），不影响使用，可以忽略。

## 装到 iPhone 桌面

用 **Safari** 打开上面的网址 → 点底部**分享按钮** → **添加到主屏幕**。
之后从桌面图标打开，就是全屏的 App，断网也能用。

> 请务必用桌面图标打开。Safari 对普通网页会清理长时间不用的本地数据，而添加到主屏幕的 App 不受这个限制。

## 更新

直接在仓库里替换 `index.html`（Add file → Upload files，同名文件会覆盖）。
改动较大时，把 `sw.js` 第一行的 `ji-v1` 改成 `ji-v2`，让手机丢掉旧缓存。

## 关于数据

- 数据存在浏览器的 localStorage 里，**换设备、换浏览器、换网址都不会同步**。
- 清除网站数据或卸载桌面图标，数据会一起清掉。
- 从本地文件（`file://`）切换到 `github.io` 网址，等于换了一个地方，旧数据不会自动带过来。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 整个应用（页面、样式、逻辑都在这一个文件里） |
| `manifest.webmanifest` | 桌面图标与全屏显示的配置 |
| `sw.js` | 离线缓存 |
| `icons/` | 应用图标（192、512、180 苹果桌面图标） |
| `.nojekyll` | 告诉 GitHub Pages 不要用 Jekyll 处理，原样发布 |
